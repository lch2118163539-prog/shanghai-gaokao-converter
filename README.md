# Shanghai Gaokao Score Converter (660 to 750)

由于上海高考总分为 660 分，而全国大部分地区高考总分为 750 分，跨地域的分数交流（如考研、求职、申请高校或日常讨论）中经常产生误解。

本项目是一个专为上海高考分数打造的开源换算工具，支持将 660 分制等比例且合乎统计学逻辑地对齐至全国通用的 750 分制。提供 Web 界面和 API 接口两种使用方式。

## ✨ 核心特性

- **主三门独立输入**：分别输入语文、数学、外语成绩（各 150 分满分）。
- **小三门双模式识别**：可直接输入等第等级（如 `A+`、`B-`）；亦可输入合规的原始赋分（70、67 等）。
- **严格边界校验**：限制非上海高考分数（如小三门非 3 分级差的异常值）输入，确保数据真实合规。
- **百分位中位数修正**：基于考生的相对省排名位置（百分位区间中位数）进行科学折算。
- **Web 界面 + RESTful API**：既可通过浏览器使用，也可作为 API 集成到其他系统。

## 📐 换算原理

上海高考小三门（选考科目）采用**等第赋分制**，单科满分 70 分，最低 40 分。本项目通过计算各档位**百分比区间的中位数**，还原该等级在全国 100 分满分制下的等效分数。

| 等级 | 上海原始分 | 对应考生百分比区间 | 百分位中位数（折算后单科满分 100） |
| :---: | :---: | :---: | :---: |
| **A+** | 70 | 前 5% (95% - 100%) | **97.5** |
| **A**  | 67 | 次 10% (85% - 95%) | **90.0** |
| **B+** | 64 | 次 10% (75% - 85%) | **80.0** |
| **B**  | 61 | 次 10% (65% - 75%) | **70.0** |
| **B-** | 58 | 次 10% (55% - 65%) | **60.0** |
| **C+** | 55 | 次 10% (45% - 55%) | **50.0** |
| **C**  | 52 | 次 10% (35% - 45%) | **40.0** |
| **C-** | 49 | 次 10% (25% - 35%) | **30.0** |
| **D+** | 46 | 次 10% (15% - 25%) | **20.0** |
| **D**  | 43 | 次 10% (5% - 15%) | **10.0** |
| **E**  | 40 | 后 5% (0% - 5%) | **2.5** |

**最终换算公式：**

$$ \text{换算后总分}(750) = \text{语数外三门总分}(450) + \sum_{i=1}^{3} (\text{小三门第 } i \text{ 选考科目的百分位中位数}) $$

## 🚀 快速开始

### 环境要求

- Python 3.8+

### 1. 克隆仓库

```bash
git clone https://github.com/lch2118163539-prog/shanghai-gaokao-converter.git
cd shanghai-gaokao-converter
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动服务

```bash
python app.py
```

启动后访问 `http://127.0.0.1:5000` 即可使用 Web 界面。

### 4. API 调用示例

```bash
curl -X POST http://127.0.0.1:5000/api/calculate \
  -H "Content-Type: application/json" \
  -d '{"yuwen":115,"shuxue":120,"waiyu":135,"elective1":"A+","elective2":"B+","elective3":"61"}'
```

返回示例：

```json
{
  "ok": true,
  "result": {
    "main_total": 370,
    "main_details": {"语文": 115, "数学": 120, "外语": 135},
    "elective_details": [
      {"input": "A+", "grade": "A+", "score": 70, "converted": 97.5},
      {"input": "B+", "grade": "B+", "score": 64, "converted": 80.0},
      {"input": "61", "grade": "B", "score": 61, "converted": 70.0}
    ],
    "original_elective_total": 195,
    "converted_elective_total": 247.5,
    "original_total": 565,
    "converted_total": 617.5
  }
}
```
